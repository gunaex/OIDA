# OIDA 2.0 Master Requirements

## Conventions

Priority is Must/Should/Could. Automation uses L0–L4 from the authority model.
“Directive” means the OIDA 2.0 Reboot Master Prompt and is not claimed as an OIDA
1.x historical source. All acceptance criteria are MVP-observable unless targeted
later.
