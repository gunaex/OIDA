# Pilot Acceptance Plan

The technical pilot verifies: migrations; project isolation; binding verification; discovery; selective exact-revision import; content fingerprint; deduplication; stale refresh without rebaseline; PM capability/status mapping; authority; idempotency/readback; reconciliation; full Phase 1–4 regression; and secret scanning.

Live checks run only when credentials exist. Real-project dogfood is separate from the canonical technical fixture and cannot be inferred from deterministic adapter tests.
