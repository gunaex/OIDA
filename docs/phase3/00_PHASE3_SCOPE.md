# Phase 3 Scope

Phase 3 proves one thin vertical slice from an exact frozen Delivery Baseline to
trustworthy execution truth. AI prepares a structured materialization plan;
humans review routing, ownership, exceptions and authorize a batch; adapters
create owner-domain work; OIDA reads it back, reconciles it and surfaces drift.

Included: Internal execution, provider-neutral target adapters, PM Again contract
boundary, manual external references, plan and execution revisions, exact lineage,
partial/unconfirmed states, idempotency, freshness, drift, audit, Project Truth and
the workspace Execution view.

Excluded: QA execution, evidence capture, acceptance packages, Gate 3, Phase 4,
change-impact automation, portfolio, graph/vector stores and an event bus. PM Again
live connectivity is optional and remains blocked in this environment.

The frozen Gate 2 baseline remains immutable. Authorization to materialize is an
operational human authority action, not Gate 3.
