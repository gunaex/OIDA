# Phase 2 Scope

## Objective

Prove Gate 2 through a real browser/API slice: consume the exact latest frozen
Requirement Baseline, generate two or three comparable solution alternatives,
let a human compare/edit/reject/regenerate/select/merge and commit one, generate a
structured delivery plan from that exact solution revision, let a human revise it,
then freeze an immutable Delivery Baseline reflected in Project Truth.

## Included

Solution and plan AI runs; structured candidates and append-only candidate
revisions; selection and merge; stable `SOL-nnn` and `PLAN-nnn` identities;
solution coverage; workstreams, items, milestones, dependencies, risks,
assumptions, effort classes and timeline assumptions; deterministic validation;
Gate 2 readiness/freeze/readback; audit, idempotency, staleness and browser views.

## Excluded

Execution/materialization, PM/QA/Infra synchronization, validation evidence,
Gate 3, change-impact workflows, portfolio, notifications, autonomous agents,
graphs, vectors, event bus and workflow engine.

AI is preparation authority only (L2). Human selection/commit controls truth and a
human project owner alone freezes Gate 2 (L0).
