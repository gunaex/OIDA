# Phase 4 Security

Every Phase 4 query scopes records by project and calls the existing membership boundary. Tests reject cross-project requirements, criteria, validation items, results, execution items, and evidence. Final authority additionally requires a human project owner; an AI actor and ordinary project member receive 403.

Evidence URLs reject credentials, non-HTTPS network schemes, and local file paths. Content hashes and status history support integrity review. Secrets remain server-side; `.env` and local acceptance databases are ignored and secret scans check tracked and untracked source material without printing values.

Prompt inputs are treated as untrusted data. Structured schema validation plus exact-reference validation prevents prompt output from inventing foreign IDs. External automated result ingestion remains closed until a trusted service identity exists.
